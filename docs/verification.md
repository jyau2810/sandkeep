# 验收记录

用户已认可细砂瓶子的效果。本轮修正装瓶时沙粒向上吸入的问题。画框先抬起并倾斜，沙粒滑到下沿和角落，再越过木框落入下方瓶口，瓶内逐层填满。已完成的瓶子和平面倒沙效果保持原有表现。测试与独立复核不代替用户对新界面和动效的视觉评价。

## 构建与运行

- `npm run build` 通过 TypeScript 检查并生成静态产物。
- 生产预览从 `/sandkeep/` 子路径加载，字体、示例和 HDR 资源正常。
- 1440px 桌面、390px 手机模拟和用户实际面板宽度 590px 均有实际截图，没有横向溢出或页面错误。
- 三种宽度的完成态画框均保持 5:3，没有透视变形。装瓶有准备、倾斜、下滑、入瓶、填充和归位时点的实拍，倒沙保留对照。三个视口截图来自同一生产构建。正常速度实际操作录屏随上架素材更新。Impeccable 独立复核的最终结论为 `disposition: ship`，依据本轮三视口实拍与新录屏的连续帧确认倾斜、沿低角向下排沙、过瓶口后积沙、归位与合塞的顺序；没有待处理的实质视觉修正。此结论仅覆盖所提供的证据，不等同于用户验收。

## 浏览器行为测试

自动化覆盖 12 个 Chromium 用例，使用实际生产构建、真实图片解码与画布输出。装瓶新增检查实际倾斜角、沙流位于变换后的画框低角下方、窄流向下延伸，窗口变化后也进行相同检查。

| 行为 | 检查方式 |
| --- | --- |
| 个人照片制作、装瓶、刷新恢复 | 生成并上传 PNG，确认没有命名步骤，刷新后比较照片与暖调记录 |
| 原色旧记录迁移 | 写入旧记录，刷新后比较暖调画面；再次保存时照片、标题、接缝与创建时间不丢失 |
| 平面拨沙、调整宽度、复原、旋涡 | 比较实际画布位图，确认划痕保留、缩放不清空、复原准确，旋涡改变颗粒 |
| 桌面拖动与方向键旋转 | 比较装瓶画布实际截图变化 |
| 错误格式与超大照片 | 提示恢复方法并保留原图；平面沙画中上传错误后仍可切换工具和复原 |
| 手机旋转与纵向滚动 | 390px 触屏模拟，通过 CDP 发送触摸事件 |
| 手机平面拨沙 | 减少动态效果开启时，手指仍可拨沙并准确复原 |
| 减少动态效果与存储被禁用 | 仍能装瓶，保存失败有可理解的提示 |
| 双向沙粒联动和操作锁定 | 控制时间逐帧推进，读取沙流透明画布的实际非透明像素；验证沉积覆盖面积继续增长、最终位图一致与忙碌状态 |
| 转场中换照片 | 两个方向分别上传另一张图片，旧动画时间结束后仍保留新图，且可以再次装瓶保存 |
| 转场中调整窗口 | 倒出、装瓶期间分别改变宽度，最终得到完整矩形沙画，位图与原完整画一致 |
| WebGL 不可用 | 显示解释和重试入口 |

本轮完整执行先通过 9 个用例；另 3 个装瓶用例因沿用旧版宽弧沙流的像素面积阈值而失败。将该检查替换为针对新窄流的倾斜角、低角位置、向下延伸和连续覆盖检查后，定向重跑这 3 个用例均通过。没有为测试修改产品动效。

自动化使用软件 WebGL，不构成实际手机硬件性能或所有浏览器版本的保证。

## 已接受瓶子的回归检查

以 `2cf32f9` 为冻结基线，在相同 538×460 画布、同一示例照片、暖调、接缝宽度 0.018 和相同渲染环境下，分别比较正面与旋转 0.68 弧度后的实际截图。两组 PNG 均完全一致。

同时逐字比较 `photoCanvas`、暖调装瓶材质、砂体几何、玻璃、瓶塞纹理和相机函数，确认未修改。临时瓶内颗粒、瓶口沙流与二维画框共用迁移时间表，瓶子的稳态渲染受到单独保护。环绕映射未改动，沿用此前四段编号照片的整圈映射检查。

## 平面沙画与材质

平面态继续使用独立的 720×432 二维画布，正面呈现于暖棕画框内。显示尺寸变化只影响 CSS，不重建或投影颗粒。页面使用一个工作台，选照片和主切换按钮在画面上方，旋转与拨沙工具按状态互斥显示在下方；命名输入与标题展示均已删除。页眉短句、介绍副文案、舞台旁白、重复玩法说明、装饰页脚和常驻保存成功提示也已删除；保留必要操作、上传限制、错误提示和一条本地处理说明。

暖调颗粒与交互依据最初 demo。拨沙沿指针路径推动颗粒，旋涡在局部区域施加旋转并逐渐停下。没有自动回原位的弹簧，划痕会保留，只有“聚回照片”明确复原。减少动态效果时仍支持直接操作，旋涡预演缩短，复原立即完成。倒沙耗时 2900ms，装瓶耗时 4000ms。倒出时倾斜真实 3D 瓶子、拔开塞子，让沙流从实际投影瓶口落到画框；装瓶时从当前沙粒位置沿倾斜画面下滑，触边后沿下沿汇至右下角，跨过木框边缘后落入下方瓶口。填充和沉降完成后才归位并合塞。一份逐粒离开、过瓶口、落地和稳定时间表同时驱动临时瓶内体积、沙流与平面颗粒。落地后从中央局部堆积向下、向两侧滚动；瓶内沙量按经过瓶口的颗粒累计计算。取消时恢复起始状态，页面隐藏时完成到终态，所有临时瓶姿、透明背景和沙流资源均会恢复或清理。减少动态效果时直接抵达相同的完整终态。

装瓶态继续使用紧凑、旋转的不规则颗粒和独立法线切面。砂体贴合内壁并填满瓶肩和瓶颈。玻璃采用本地 HDR 与透明 Fresnel 轮廓近似，没有物理折射或真实沙粒碰撞的承诺。

本轮数值检查覆盖实际 85,428 粒装瓶路线，确认画框固定倾斜后的下滑路线在屏幕上只向下、各阶段交接唯一、出框点与沙流起点一致、原有倒沙路线数据不变。先前临时体积检查已验证清空采样画布后颜色有限、颗粒不超出瓶内轮廓和重复切换复用 GPU 缓冲。数值检查不能证明真实物理或视觉自然。
