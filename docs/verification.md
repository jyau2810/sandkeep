# 验收记录

本轮修正倒出时横向喷射、旋转后瓶口方向错乱的问题，并按用户要求精简界面。标题为“把回忆装进沙子里”。接缝设置、旋转按钮、漩涡选项和本地处理页脚已删除。两种完成态共用画面底部中央的操作提示，动画期间隐藏。

## 构建与实际画面

`npm run build` 通过 TypeScript 检查并生成生产文件 `index-CwCFdUnA.js`。1440px 桌面、390px 手机模拟和 590px 用户面板均采集了实际截图，没有横向溢出或页面错误。每个宽度覆盖倒出 500、900、1400、2100、2700ms、平面完成态及装瓶 1800、2800ms。另有旋转后的实际倒出样本。

倒出先把瓶口翻转到画框中央上方，再让细沙沿窄列向下加速。小沙堆逐渐向照片位置铺开，最后画框展开到完整大小。照片的局部旋转与整瓶倾倒分开计算，任意角度不再改变落沙方向。该过程是按沙粒事件编排的近似，没有真实颗粒碰撞或物理折射。

## 浏览器行为测试

`npm test` 使用实际生产构建执行 14 个 Chromium 用例。

```text

```

本轮重力沙流回归在修改前先失败。旧构建 `index-C0Z__O3A.js` 的实际横向沙流宽度为 239 CSS 像素，超过 20 像素阈值。修复后的用例在 0、72、180 度读取透明画布的实际沙流范围，验证窄列向下、落点对齐画框中央以及各角度的一致性。它不读取渲染函数中的坐标常量。

| --- | --- |

## 已认可瓶子的保护

以 `2cf32f9` 为冻结基线，在相同 538×460 画布、示例照片、暖调、接缝宽度 0.018 和渲染环境下，分别比较正面与旋转 0.68 弧度后的实际 PNG。两组完全一致。

七个受保护函数 `corkTexture`、`photoCanvas`、`packedSandMaterial`、`packedSandGeometry`、`sandRadiusAt`、`clearGlass` 和 `placeCamera` 逐字相同。装瓶的 `poseAssembly` 与完整迁移计划也与本轮前的 `b59cb82` 相同。临时装瓶沙面继续复用已认可的受光材质、法线贴图和原有颗粒尺度。

数值检查覆盖三种布局、五个旋转角度及 201 个时间点，共 3015 个准备与倒出姿态。瓶身和可见瓶塞均留在视口内，并避让底部 60px。第一次实际出瓶晚于姿态完成，瓶口与画框保持到最后落地之后。数值检查不替代实际画面检查，也不证明真实物理。

## 素材与复核

上架的四张 PNG 与正常速度 MP4 均已从本轮实际生产页面重采。视频包含拖动旋转后倒出、拨沙、复原、倾斜画框装瓶及再次旋转，没有加速交互或补绘效果。素材文件均小于 3 MB，PNG 来源元数据完整。

新的 Impeccable 独立复核结论为 `disposition: ship`，没有提出需要修改的项。复核阅读了用户拒绝的截图、三宽完成态、连续倒出帧、两个旋转样本及实际录屏连续帧。工程内保留修改前的实际复现、失败与通过记录、当前连续帧和受保护瓶子的对照结果。该结论不代表用户已验收新动效。

## 部署与范围

[GitHub Pages](https://jyau2810.github.io/sandkeep/) 由主分支工作流发布。上线后核对 JavaScript 文件与本地构建一致，再在独立浏览器会话验证倒出、拨沙、复原、装瓶、旋转和刷新恢复。

照片仍在本机处理，最新瓶子仍保存在当前浏览器。没有下载、账号、后端或跨设备同步。本轮不提交 1024 报名表单。内部测试与复核不代替用户对新动效的视觉验收。
