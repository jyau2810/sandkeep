# 验收记录

日期为 2026-10-15。以下是对当前实现的实际检查，不代表用户已确认视觉效果。

## 构建与运行

- `npm run build` 通过 TypeScript 检查并生成静态产物。
- 使用生产预览的 `/sandkeep/` 子路径加载，资源和字体正常。
- 桌面 1440px、手机模拟 390px 和用户实际面板宽度 590px 截图均未发现横向溢出；正常场景未捕获页面或控制台错误。
- 在 Codex 内嵌浏览器打开并操作实际预览。

## 浏览器行为测试

`npm test -- --reporter=line` 的 6 个 Chromium 用例通过。

| 行为 | 证据 |
| --- | --- |
| 个人照片制作、命名、暖调装瓶、刷新恢复 | 上传真实生成的 PNG，刷新后比较照片、标题和配色 |
| 桌面拖动与方向键旋转 | 比较 Canvas 实际截图变化 |
| 错误格式与超大图片 | 显示恢复提示，保留原瓶子，之后可继续上传 |
| 手机布局、横向触摸与纵向滚动 | 390px 触屏模拟，通过 CDP 发送触摸事件 |
| 减少动态效果与存储被禁用 | 仍可完成装瓶，保存失败有提示 |
| WebGL 不可用 | 显示解释和重试入口 |

自动化使用软件 WebGL，首次初始化保留较宽的等待窗口。测试不构成实际手机硬件性能或所有浏览器版本的保证。

## 环绕图片检查

`node scripts/verify-wrap.mjs` 通过。用四段不同颜色、标有 1 至 4 的测试图，实际采集 0°、90°、180°、270° 和 360° 图像。人工查看确认文字未镜像、四段按顺序环绕、背面接缝连接 4 与 1、整圈回到初始画面。完整照片边框保持可见。

## 材质与交互

颗粒使用原始彩砂 demo 的采样、方粒、暗缝与高光算法。内置示例使用同一只代码绘制的猫，便于和用户给出的参考图比较。松散态可拨动颗粒；瓶身使用同一生成器烘焙的颗粒层，避免透射模糊洗掉暗缝。

实际检查了原色、暖调、拨动、装瓶和旋转。玻璃使用本地 HDR 反射和透明 Fresnel 轮廓近似，没有物理折射或真实沙粒碰撞的承诺。用户对最终视觉的评价与自动化、独立复核分开记录，不能以测试通过代替用户认可。

## 范围与限制

- 手机验证为 Chromium 触屏模拟，未声称已经在 iPhone 或 Android 真机验收。
- 最新瓶子仅保存在当前浏览器，不跨设备同步。
- 没有下载、导出、账号和后端。
