# 验收记录

用户已认可静止细砂瓶子的效果。本轮修正装瓶时画框提前显空、瓶内临时沙面质感不一致的问题。余沙保留二维面积，沿重力逐步流向出口。已经落地的沙子复用原有受光材质和法线贴图，只有空中细沙使用粒子。静止瓶子与原有倒出过程继续保持原有表现。测试与独立复核不代替用户对新动效的视觉评价。

## 构建与运行

- `npm run build` 通过 TypeScript 检查并生成静态产物。
- 生产预览从 `/sandkeep/` 子路径加载，字体、示例和 HDR 资源正常。
- 1440px 桌面、390px 手机模拟和用户实际面板宽度 590px 均有实际截图，没有横向溢出或页面错误。
- 三种宽度的完成态画框均保持 5:3，没有透视变形。装瓶实拍覆盖 800、1300、1800、2300、2800、3200、3500、3700ms，同一生产构建为 `index-C0Z__O3A.js`。画框余沙仍有可见厚度，瓶内已落定部分呈现连续受光砂面。正常速度录屏已重新采集。Impeccable 独立复核结论为 `disposition: ship`。连续帧确认余沙和瓶内堆积共同变化，空框后的短暂尾流仅为已经离框的最后细沙，完成后的材质衔接没有可见跳变。该结论属于内部复核，不等同于用户验收。

## 浏览器行为测试

自动化覆盖 12 个 Chromium 用例，使用实际生产构建、真实图片解码与画布输出。装瓶检查实际倾斜角、沙流位于画框低角下方、窄流向下延伸，窗口变化后也检查相同关系。新增实际画布余沙检查，在 2300ms 仍超过 10,000 个与空框不同的像素，在 2800ms 仍超过 1,000 个，防止颗粒只在一维边缘互相覆盖。

## 已接受瓶子的回归检查

以 `2cf32f9` 为冻结基线，在相同 538×460 画布、同一示例照片、暖调、接缝宽度 0.018 和相同渲染环境下，分别比较正面与旋转 0.68 弧度后的实际截图。两组 PNG 均完全一致。

同时逐字比较 `photoCanvas`、暖调装瓶材质、砂体几何、玻璃、瓶塞纹理和相机函数，确认未修改。临时瓶内颗粒、瓶口沙流与二维画框共用迁移时间表，瓶子的稳态渲染受到单独保护。环绕映射未改动，沿用此前四段编号照片的整圈映射检查。

## 平面沙画与材质

平面态继续使用独立的 720×432 二维画布，正面呈现于暖棕画框内。显示尺寸变化只影响 CSS，不重建或投影颗粒。页面使用一个工作台，选照片和主切换按钮在画面上方，旋转与拨沙工具按状态互斥显示在下方；命名输入与标题展示均已删除。页眉短句、介绍副文案、舞台旁白、重复玩法说明、装饰页脚和常驻保存成功提示也已删除；保留必要操作、上传限制、错误提示和一条本地处理说明。

暖调颗粒与交互依据最初 demo。拨沙沿指针路径推动颗粒，旋涡在局部区域施加旋转并逐渐停下。没有自动回原位的弹簧，划痕会保留，只有“聚回照片”明确复原。减少动态效果时仍支持直接操作，旋涡预演缩短，复原立即完成。倒沙耗时 2900ms，装瓶耗时 4000ms。装瓶时，画框先抬起、倾斜，再让余沙按累计面积坐标向角落移动。颗粒不会提前汇成零宽度的边线。离框、过瓶口、落地和稳定共用同一份计划；瓶内压实沙量按已经落地的颗粒累计。临时填充克隆已认可的材质，共享颜色图、法线图和侧面几何，UV 保持原有尺度。顶面为受光的小沙堆，侧面边界与顶面使用同一高度函数，接近填满时逐渐铺平。空中颗粒落地后消失，不再构成整个瓶内砂体。取消、换图、隐藏页面和减少动态效果沿用原有终态与清理路径。

装瓶态继续使用紧凑、旋转的不规则颗粒和独立法线切面。砂体贴合内壁并填满瓶肩和瓶颈。玻璃采用本地 HDR 与透明 Fresnel 轮廓近似，没有物理折射或真实沙粒碰撞的承诺。

本轮数值检查覆盖完整画面和拨动后的 85,428 粒装瓶路线，确认起始位置、屏幕向下移动、出口交接和阶段守恒。默认完整画面最后一粒约 3240ms 离框、3300ms 过瓶口、3400ms 落地、3440ms 稳定。空框后的外部沙流仅保留 60ms，最后落地延迟为 160ms。实际浏览器截图中，2300ms 与 2800ms 的暖色砂粒面积分别为 85,976 和 41,033 像素，三个视口读取相同的原生画布；该阈值统计与上面的空框差异回归采用不同算法，不将两者混作同一计数。

瓶内体积探针检查私有材质、共享纹理与几何、裁剪平面隔离、临时资源释放和空中颗粒区间。模型使用截面体积积分与小圆锥顶面，属于解析近似。数值检查不证明真实物理、真机性能或视觉自然。
