# 瓶装沙画的实物参考

2026-10-15，用户认可上一版比早期效果更好，同时指出透视、立体感和黑色颗粒孔隙仍不自然。本轮用实物照片校正装瓶后的材质方向，保留照片环绕一圈和拖动旋转的玩法。

## 参考来源

### Smithsonian 的 Mary Heye Bottle

[馆藏页面](https://americanart.si.edu/artwork/mary-heye-sand-bottle-118881)提供 Andrew Clemens 于 1883 年制作的作品照片。馆方记录材料为天然有色岩砂和药瓶，并说明沙粒逐层排列、压实后形成图案。

[正面实拍](https://ids.si.edu/ids/deliveryService?id=SAAM-2021.69_1&max=960)中，图案形成连续色块。细颗粒的明暗接近所在色块，玻璃的亮边、瓶底和瓶口保留厚度。沙体继续延伸进瓶肩和瓶颈。

### 佩特拉沙画瓶实拍

[图片页面](https://www.pikist.com/free-photo-xkbrm)和[实拍大图](https://p0.pikist.com/photos/963/157/petra-jordan-vacations-travel-middle-east-sand-sand-painting-glass-bottle-bottle.jpg)展示多只装满彩砂的玻璃瓶。曲面的高光、侧面压缩的图案和瓶底的弧面共同表现体积。砂面细密，黄色和橙色区域没有遍布黑色孔洞。

### 佩特拉沙画艺人的材料处理

[AFAR 的现场报道](https://www.afar.com/magazine/in-jordan-a-sand-artist-captures-the-regions-geology-and-history)介绍艺人 Reda Amarat 将采集的岩石磨成很细的粉砂。这个材料细度也解释了实拍中连续、密实的色面。

以上照片仅用于观察和提供外链，没有作为产品纹理复制进站点。

## 对当前实现的判断

以下是对照片和当前代码的判断，不是来源网站对本项目的评价。

上一版把松散沙粒的黑色背景和留白一起烘焙到瓶身。黑底在小尺寸瓶身上变成了大面积高反差斑点，更像噪声滤镜。密实砂面需要用相邻砂粒的局部颜色填满空隙，再用细微明暗表现颗粒。

上一版装瓶表面使用不受灯光影响的材质。即使它绕着真实圆柱旋转，正面和侧面的明暗仍接近，容易看成一张贴在瓶内的平面图。

上一版桌面相机高度约为 1.20，而沙顶约为 1.37、瓶塞顶约为 2.60。这个机位不能同时提供自然的砂面与瓶口俯视。新机位要用同一个相机解释瓶口、瓶底、瓶肩和接触阴影。

## 本轮调整边界

装瓶态改为贴合内壁、延伸到瓶肩和瓶颈的砂体。表面采用细密的局部色颗粒、粗糙光照和轻微凹凸，减少黑色斑点。玻璃继续保持照片可读，避免再次用透射模糊洗掉细节。

松散态保留原先可拨动的彩砂体验。两种状态表达不同的堆积密度。上传、配色、命名、装瓶、环绕一圈和本地保存保持原有流程。
