# 1024 上架材料

填写入口为 [个人参赛](https://1024.flatincbr.com/submit?entryType=individual)。该页面已在 Chrome 中打开。本目录用于准备材料，不代表已经提交参赛作品。

## 表单文案

- 作品名称：**砂藏 Sandkeep**
- 参赛类型：**个人参赛**
- 建议赛道：**小工具区**
- 一句话介绍：**把照片化成彩砂，藏进可旋转的玻璃瓶，留住一整圈回忆。**
- 体验方式：**访问网页**
- 访问地址：部署验收后写入 `fields.json`。
- 使用说明：复制 [instructions.md](instructions.md) 的全文。
- 支持平台：以 `docs/verification.md` 的实际验证结果为准。

## 上传顺序

素材放在 `media/`。第一张用于封面，建议先封面，再桌面截图、手机展示图和 MP4 演示。

## 已核对的页面约束

2026-10-15 在 Chrome 登录页面读取。

| 字段 | 页面限制 |
| --- | --- |
| 作品名称 | 最多 30 字 |
| 一句话介绍 | 5 至 60 字 |
| 使用说明 | Markdown，最多 2000 字 |
| 体验方式 | 访问网页 / 下载产物 |
| 访问地址 | 最多 2048 字符 |
| 平台 | 手机 / 电脑 |
| 素材 | PNG、JPG/JPEG、WEBP、GIF、MP4 |
| 素材数量与大小 | 最多 10 个，每个不超过 300 MB |
| 建议画幅 | 16:9，首个素材为封面 |

## 提交前

- 打开正式体验地址，亲自换一张照片，完成装瓶和旋转。
- 根据当前版本确认名称、赛道和支持平台。
- 上传 `media/` 中的正式素材。
- 检查没有把个人照片、登录凭证或内部信息带入素材。
- 由参赛者点击“确认提交作品”。页面说明提交后会锁定作者和参赛名额。
