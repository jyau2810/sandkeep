# 上架素材

以下 PNG 和 MP4 均来自实际运行的砂藏页面。没有用效果图替代应用截图。内置猫咪为代码绘制的示例，不包含个人照片。

| 顺序 | 文件 | 内容 |
| --- | --- | --- |
| 1 | [01-cover.png](01-cover.png) | 1920×1080，暖调瓶子与完整制作界面，作为封面 |
| 2 | [02-loose-sand.png](02-loose-sand.png) | 1920×1080，带画框的正面平面沙画 |
| 3 | [03-sand-swirl.png](03-sand-swirl.png) | 1920×1080，平面暖调沙画的旋涡交互 |
| 4 | [04-mobile.png](04-mobile.png) | 390px 宽的手机布局全页截图 |
| 5 | [05-demo.mp4](05-demo.mp4) | 1280×720，H.264、yuv420p、无音轨的实际操作录屏 |

建议依照表格顺序上传，共 5 个文件。当前每个文件均小于 3 MB。手机截图为纵向，其余素材为 16:9。

演示视频依次展示旋转示例、拆开拨沙、旋涡、聚回照片、装瓶和拖动旋转。视频去除了启动等待，没有加速交互或补绘效果。

截图和原始 WebM 可通过 `node scripts/capture-media.mjs <体验地址>` 重新采集。MP4 使用 FFmpeg 的 libx264 编码。浏览器软件渲染录屏用于展示操作，不作为真机性能测量。
